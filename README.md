# Vetor256.

> **Tecnologia que resolve problemas reais.**

Site institucional da **Vetor256.**, desenvolvido para apresentar a
empresa, seus serviços, projetos, experiência e canais de contato de
forma moderna, objetiva e responsiva.

------------------------------------------------------------------------

## 🚀 Sobre o projeto

A **NovaVetor256** é uma nova versão do site institucional da Vetor256.,
construída com foco em:

-   apresentação profissional da empresa;
-   comunicação clara dos serviços oferecidos;
-   experiência responsiva em desktop e dispositivos móveis;
-   navegação simples e objetiva;
-   identidade visual própria;
-   canais de contato diretos;
-   preparação para otimização de SEO.

O projeto foi desenvolvido com **HTML5, CSS3 e JavaScript**, mantendo
uma estrutura simples, leve e fácil de evoluir.

------------------------------------------------------------------------

## ✨ Principais características

-   🎯 Hero section com proposta de valor clara;
-   🧩 apresentação dos principais problemas que a tecnologia pode
    resolver;

-   🎨 identidade visual baseada em preto, laranja e amarelo;

## 🎨 Identidade visual

A identidade visual utiliza como base as cores da Vetor256.:

  Cor         Aplicação
  ----------- ----------------------
  `#080808`   Fundo principal
  `#111111`   Seções escuras
  `#FFFFFF`   Conteúdo e contraste
  `#FF5A00`   Laranja principal
  `#FFBD2E`   Amarelo
  `#B8B8B8`   Textos secundários

O logotipo utiliza a combinação de **laranja, amarelo e preto**,
reforçando a identidade visual da empresa.

------------------------------------------------------------------------

## 📱 Responsividade

O layout foi desenvolvido para diferentes tamanhos de tela:

-   🖥️ desktops;
-   💻 notebooks;
-   📱 smartphones;
-   📲 dispositivos com telas menores.

No mobile, a navegação é substituída por um menu lateral acionado pelo
botão hamburger.
